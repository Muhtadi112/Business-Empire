# Business Empire

Android prototype for a single-player business management and logistics tycoon.

## Prototype features
- CEO dashboard and company cash balance
- Time controls: pause, 1x, 2x, 5x, 10x
- Purchase additional trucks
- Simulated delivery income, operating costs, and activity log

Economy values are placeholders. Persistent saves, world map, contracts, subsidiaries, AI competitors, and additional transport modes are not implemented yet.

## Build APK
Every push to main triggers **Android APK Build**. You can also run it manually from the Actions tab.

After a successful run, open the workflow run, download the **Business-Empire-debug-apk** artifact, extract it, and install app-debug.apk. This is a debug build for testing, not a Play Store release.
