# Business Empire – By Adi (3D Prototype)

This is the new Godot 4 project track. The previous Kotlin/Compose prototype remains untouched on the main branch.

## Prototype 0.1
- Landscape 3D scene with a small town road, simple buildings and warehouse.
- Drivable starter truck with chase camera.
- Touch-friendly steering, throttle and reverse/brake controls.
- First delivery contract: drive to the green warehouse marker to earn Rp12,500,000.
- Basic company cash HUD.

## Run
Open this folder in Godot 4.4.1 or newer and run `scenes/main.tscn`.

## Direction
Semi-realistic low-poly 3D for Android performance. This is a gameplay foundation, not a final art pass. Next milestones: proper vehicle physics, loading/unloading, individual fleet and drivers, buildable facilities, contracts, AI traffic and save system.
